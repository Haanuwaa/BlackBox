# Analysis module

Analysis consumes normalized incident snapshots and must never be required by collection. V0.3
accepts portable prior executable observations as caller-supplied context but has no storage
dependency. V0.7 adds portable, versioned incident-shape extraction and bounded deterministic
clustering; generic cached values and overrides still arrive through the application boundary.
V0.8 adds bounded probabilistic workload recognition and capped soft anomaly reranking while
retaining raw evidence. V0.9 composes the established components into a versioned diagnosis with
typed evidence links, calibrated confidence, recurrence context, and a stable configuration
fingerprint. Native ML remains unshipped because the material-benefit gate is not satisfied.
